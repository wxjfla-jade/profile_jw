# Self-Introduction Portfolio

A single-page personal portfolio highlighting business + data + AI experience across go-to-market, market research, growth operations, and analytics projects.

> **AI 辅助开发说明**
> 本项目为 **AI 辅助开发**（AI-assisted）完成，特此说明，避免误解为纯手工开发。
> - **人**：定义问题与验收标准——确定要展示的经历、脱敏口径（隐去姓名/电话/微信，模糊学校与公司名）、信息架构与视觉要求，并逐项核对内容真实性。
> - **AI**：生成实现——根据要求生成 HTML/CSS 页面结构、样式与内容排版，并按要求迭代版式（项目三段式、技能卡片、竖排布局等）。
> - **人**：建立验证体系并复核——用浏览器内核渲染截图检查各板块显示、校验敏感信息清除情况、核对数字与原始素材一致，确认无误后才定稿。

## Deploy

This is a static site. Push to a GitHub repository, then:
**Settings → Pages → Build and deployment → Source: Deploy from a branch → main / root → Save.**
Live at `https://<username>.github.io/<repo-name>/` in ~1 minute.

## Files

- `index.html` — the full single-page portfolio (no build step, no dependencies)
- `.nojekyll` — disables Jekyll processing so the static file is served as-is
